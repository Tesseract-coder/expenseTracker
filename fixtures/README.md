# Statement fixtures

Anonymized sample statements, one per built-in bank profile. Names, account numbers, VPAs and
reference numbers are fabricated. Layouts follow each bank's net-banking download format as
publicly documented. **Verify against your own downloads.** If a real file doesn't match, add a
redacted copy here and adjust the profile.

| File                    | Profile            | Quirks exercised                                                                                                        |
| ----------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| `hdfc/savings.xlsx`     | `hdfc_savings_v1`  | preamble rows, `****` separator, dd/mm/yy text dates, wrapped narration, two identical ₹20 UPI payments, summary footer |
| `hdfc/credit-card.csv`  | `hdfc_cc_v1`       | single amount + `Debit / Credit` column, payment received                                                               |
| `icici/savings.xlsx`    | `icici_savings_v1` | real Excel date cells + numeric amount cells, serial-number column                                                      |
| `icici/credit-card.csv` | `icici_cc_v1`      | `BillingAmountSign` CR column, dates with time                                                                          |
| `sbi/savings.txt`       | `sbi_savings_v1`   | tab-delimited, `1 Oct 2026` dates, account-info preamble                                                                |
| `sbi/credit-card.csv`   | `sbi_cc_v1`        | `D`/`C` type column                                                                                                     |
| `axis/savings.csv`      | `axis_savings_v1`  | dd-mm-yyyy, OPENING BALANCE row, repeated page header                                                                   |
| `axis/credit-card.csv`  | `axis_cc_v1`       | `Debit`/`Credit` words                                                                                                  |
| `kotak/savings.csv`     | `kotak_savings_v1` | Amount + `Dr / Cr`, balance with its own `Dr / Cr` column                                                               |
| `kotak/credit-card.csv` | `kotak_cc_v1`      | `Cr` suffix inside the amount, no type column values                                                                    |

Each fixture has a golden `*.expected.json` (profile id + parsed output) checked by
`packages/shared/src/import/golden.test.ts`. Regenerate after an intentional change with
`UPDATE_GOLDEN=1 pnpm --filter @kharcha/shared test golden`, then review the diff.
XLSX fixtures are generated by `packages/shared/scripts/generate-fixtures.ts`.
